# Rolling Around

一個可愛的 3D 滾球收集遊戲，使用 Three.js + TypeScript + Vite 打造。從一顆 1 公尺的糖果球出發，滾過花圃、吞下羊群、捲走城市，最後連月亮、行星和星系都吞下去！

## 遊戲玩法

- **吃得下比你小的東西**：物件體積小於球的 60% 就會黏上球，球隨之長大
- **撞到太大的東西會彈開**，高速撞上去還會把剛黏上的東西撞掉
- **連擊**：1.4 秒內連續吞食會累積連擊，音效一路往上爬音階，成長加成最高 +30%
- **收集圖鑑**：40 種物件（小花、綿羊、公車、摩天輪、城堡、火山、城市、彩虹、月亮、行星、太陽、星系……），第一次吃到會標記「新發現」
- **沒有上限**：球可以一直長大，從草地上的彈珠一路滾到吞下星系
- **稱號**：小彈珠 → 雪球 → 滾石 → 推土球 → 城鎮吞噬者 → 摩天巨球 → 怪獸級 → 天災級 → 小行星 → 移山巨球 → 大陸吞噬者 → 月球級 → 行星級 → 恆星級 → 星系級 → 宇宙之球
- **長按衝刺**：按住 Shift 加速 1.6 倍，消耗體力條（約 3 秒用完），用光要喘一下才能再衝
- **道具**：磁吸（把附近小東西吸過來）、衝刺（速度 ×1.7）、巨大化（體積 +25%）
- **小動物會逃跑**：當你大到能吃掉牠們時，綿羊、鴨子、路人會慌張地跳著逃走

### 模式

| 模式 | 說明 |
|------|------|
| 限時挑戰 | 4 分鐘內滾到最大，結束時顯示成績、圖鑑與最佳紀錄 |
| 自由滾動 | 沒有時間限制，暫停畫面可看目前的圖鑑 |

## 操作方式

| 按鍵 | 功能 |
|------|------|
| **W / A / S / D** 或 **方向鍵** | 滾動 |
| **滑鼠移動**（點畫面鎖定）/ **Q / E** | 轉動視角 |
| **空白鍵** | 跳躍 |
| **Shift**（按住） | 衝刺（消耗體力） |
| **P** / **Esc** | 暫停 / 繼續 |
| **M** | 背景音樂開關 |

手機與平板：左半邊拖曳滾動、右半邊拖曳轉視角，右下角按鈕跳躍（點）與衝刺（按住）。

## 世界與畫面

- 無限程序生成的世界，區塊隨球的大小放大（100 → 400 → 1600 → 6400 公尺，之後每級再放大 4 倍、沒有上限），大球也看得到完整地平線
- PBR 光影：軟陰影、天空環境光、亮面糖果球、會反射天空的流動水面、陽光反光的光暈；日夜循環（一天 4 分鐘）、星空、隨機降雨（雨天地面更滑）
- 真實手感：起步煞車俐落、轉彎有抓地力、陡坡會往下滾、落地會彈一下；掉進水裡會濺起水花、浮在水面滑行並留下漣漪
- 球再大也一樣好操控：100 公尺之後速度、跳躍與重力跟著球等比放大，巨球不會變成慢動作
- 電腦跑不動時會自動切換效能模式（關光暈、降解析度與陰影）
- 程序化背景音樂與音效，全部由 Web Audio API 即時合成：有空間殘響與立體聲定位，滾動聲會隨草地 / 水面變化，白天有鳥叫、晚上有蟲鳴

## 技術棧

- **Three.js** — 3D 渲染引擎
- **TypeScript** — 型別安全
- **Vite** — 開發與建置
- **Web Audio API** — 程序化音效與音樂

## 本地開發

```bash
npm install      # 安裝依賴
npm run dev      # 啟動開發伺服器
npm test         # 遊戲公式單元測試
npm run build    # 建置生產版本
npm run preview  # 預覽生產版本
```

## 部署資訊

本專案部署於 [Render](https://render.com/) 靜態網站服務：

- **線上網址**：https://katamari-web-game.onrender.com/

## 專案結構

```
rolling-around/
├── src/
│   ├── main.ts              # 程式進入點
│   ├── rules.ts             # 遊戲公式（速度、跳躍、體力、吃的判定、稱號、生成密度）
│   ├── GameManager.ts       # 主循環、模式、碰撞、連擊、計分
│   ├── Engine.ts            # 渲染器、相機、光照
│   ├── Player.ts            # 玩家球體、物理、黏附物件
│   ├── WorldManager.ts      # 無限區塊、地形、物件生成與移動
│   ├── ObjectFactory.ts     # 40 種物件型錄與道具
│   ├── WeatherSystem.ts     # 天空、日夜、天氣
│   ├── AudioManager.ts      # 音效與背景音樂
│   ├── Effects.ts           # 粒子、水花、漣漪
│   ├── materials.ts         # 共用材質與程序化貼圖
│   ├── HUD.ts               # 介面、暫停 / 結算畫面、圖鑑
│   └── TouchControls.ts     # 觸控操作
├── tests/rules.test.ts      # 單元測試
├── index.html
└── style.css
```

## 注意事項

- 需要支援 WebGL 的瀏覽器（建議 Chrome、Edge、Firefox、Safari 最新版）
- 音效需要點擊開始按鈕後才會啟動（瀏覽器限制）
- 支援 `prefers-reduced-motion` 無障礙設定
